# tool-driver-cli-spec 1.0.0

面向真实应用与设备的独立 Agent CLI 操作规范，机器 Schema 版本为 `1.0`。

本版本冻结核心响应、计划、回执、能力发现、证据与交付清单，并提供操作状态、工作流和集合读取的可选公共结构。
授权按任务范围核实；执行、修改、保存和验证分别记录。未知结果不默认未执行，取消受理不表示原生停止。

规范包包含实施与迁移指南、离线符合性校验、规范副本检查、ZIP 校验及命令边界测试。
采用者固定规范包与公共 Schema，不修改公共定义；具体产品按自己的能力和实际环境验收。

可复现的文件模式探针使用独立浏览器读取生成的 SVG、重新打开，并检验写后失败的状态报告。
该证据只覆盖此文件样本；规范稳定不代表具体应用、设备产品或 SkillHub 原生多文件分发已完成验收。

通过 GitHub Release 交付 ZIP、manifest 和 SHA-256 清单，不发布 npm。
