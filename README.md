# tool-driver-cli-spec

面向真实应用与设备的 Agent CLI 操作规范。

本仓库以私有方式维护，以 `ai-native-cli-spec` 为参照，记录如何通过 CLI 驱动工具本体，并核实其状态、执行结果与产物。

## 定位

API Client CLI 通常面向服务接口和资源操作。Tool Driver CLI 面向应用或设备实例，需要理解工具的运行环境、对象模型、会话状态和执行机制。

CLI 可以使用 Python、Go、Java 或其他语言实现。这里的 driver 表示驱动工具本体，与实现语言和分发格式无关。

首批参照对象是 `kicad-cli`、`xpedition-cli` 和 `creo-cli`。后续可按实际需求扩展到其他应用或设备。

## 拟定范围

- 通用机器契约：结构化输出、错误、能力发现、版本协商、可信内容边界和契约测试。
- 工具操作契约：实例与对象身份、会话、内存与磁盘状态、变更计划、保存、依赖、读回、恢复和操作回执。
- 内部交付约定：私有仓库、构建产物、安装、更新、版本配套与验证证据。
- 按需领域规范：单位、坐标系、工程不变量和领域检查，不将 CAD 或硬件规则强加给所有应用。

## 与现有规范的关系

参考 `ai-native-cli-spec` 的通用机器契约，针对驱动真实工具时的状态和执行语义补充规则。

文档要求按内部使用和协作需要精简；兼容性、变更记录、验证证据及机器可读契约仍需保留。开源展示和公开分发约定不作为默认要求。
