# 机器结构与状态反例

这些示例是人工构造的协议样例，全部使用合成身份、版本和证据引用。
它们没有连接真实应用或设备，也没有交付示例 manifest 中声明的组件文件。

`index.json` 明确记录每个样例使用的 Schema 和预期结果。
`valid/` 展示已应用未保存、部分失败、结果未知、能力声明和开发证据。
`invalid/` 包含把部分修改伪装为成功、未知结果自动重试、错误聚合检查、缺少试执行观察以及不安全组件路径等反例。

```powershell
python scripts/check_spec.py
```

脚本检查 JSON Schema 及可静态判断的状态关系，不能证明回执由实际工具产生，也不能证明领域正确性。
